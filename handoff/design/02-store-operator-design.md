# MiriYum 식당 대표자 화면 디자인 상세 지시서

## 문서 사용법과 공통 구조

저장소를 볼 수 없는 디자인 AI가 사용하는 독립 문서다. 사용자에게는 `식당 대표자`, 서비스명은 `MiriYum Partner` 또는 `매장 관리`를 사용한다. 개발 내부 역할명은 화면에 노출하지 않는다.

공통 셸은 로고, 현재 매장명, 데스크톱 사이드바·모바일 메뉴, 대표자 프로필, 로그아웃, 페이지 제목·설명, 저장 결과와 오류 영역을 포함한다. 1차 MVP는 대표자 한 명과 매장 한 곳의 관계를 기본으로 한다. 고도화 메뉴를 숨겨도 핵심 관리 메뉴가 재배치되어 빈 공간이 없어야 한다.

---

## 1차 MVP 화면

### 1. 식당 대표자 회원가입 화면

#### 화면 목적
식당 대표자 전용 계정을 생성한다. 매장 등록은 가입 다음 단계다.

#### 반드시 포함할 요소
MiriYum Partner 표시, 이메일·이메일 확인, 휴대전화 본인확인, 표시 이름, 비밀번호·확인과 표시/숨김, 가입 버튼, 대표자 로그인 이동, 고객 서비스 이동, 약관·개인정보처리방침.

#### 화면 상태와 문구
기본, 필수 누락, 형식 오류, 이메일·휴대전화 중복, 확인 만료, 처리 중, 성공, 실패. `회원가입이 완료되었습니다. 로그인해 매장을 등록해 주세요.`

#### 성공 후 이동
대표자 로그인. 자동으로 매장을 만들거나 로그인하지 않는다.

#### 포함하지 않을 요소
사업자등록번호, 매장명, 입점 심사 자료, 직원·공용 계정, 소셜 가입, 플랫폼 운영자 역할.

### 2. 식당 대표자 로그인 화면

#### 화면 목적
식당 대표자 계정으로 매장 관리 서비스에 진입한다. 일반 사용자·플랫폼 운영자 로그인과 명확히 구분한다.

#### 반드시 포함할 요소
MiriYum 로고, MiriYum Partner 서비스명, `식당 대표자 로그인`, 이메일, 비밀번호, 표시·숨김, 로그인, 회원가입, 실패 메시지, 고객 서비스 안내, 약관·개인정보처리방침.

#### 입력란
- 이메일: 라벨 `이메일`, 예시 `owner@example.com`, 빈값·형식 오류
- 비밀번호: 표시·숨김, Enter 로그인, 빈값 오류

#### 화면 상태와 문구
- 기본, 이메일 형식 오류, 필수 누락, 처리 중, 로그인 실패, 재시도 대기, 세션 만료
- 실패: `이메일 또는 비밀번호를 확인해 주세요.`
- 제한: `잠시 후 다시 시도해 주세요. 54초 후 재시도할 수 있습니다.`
- 만료: `로그인 시간이 만료되었습니다. 다시 로그인해 주세요.`

#### 로그인 성공 후 이동
- 1차 MVP 등록 매장 없음 → 매장 등록
- 등록 매장 있음 → 매장 관리 홈
- 고도화 입점 심사가 실제 활성화된 경우에만 미신청 → 입점 신청, 심사 중 → 신청 현황
사용자가 로그인 화면에서 분기를 선택하지 않는다.

#### 포함하지 않을 요소
1차 MVP 비밀번호 찾기, 소셜·휴대전화·직원·플랫폼 로그인, 사업자번호, 매장 선택기, 로그인 상태 유지.

#### 선택 요소
서비스 소개, 관리 기능 이미지, 고객 서비스 이동, 문의처, 데스크톱 좌우 분할.

### 3. 매장 미등록 안내·매장 등록 화면

#### 화면 목적
로그인한 대표자가 첫 매장을 즉시 등록한다. 1차 MVP에는 플랫폼 승인 대기가 없다.

#### 반드시 포함할 요소
- 진행 안내와 대표자 계정 요약
- 사업자등록번호, 업종 `카페/베이커리/기타`
- 매장명, 설명, 지역, 주소
- 매장 카테고리 1개, 허용 태그
- 운영 모드: 일반 예약, 메뉴 홀드, 픽업
- 저장·취소, 필수 표시, 개인정보 안내

#### 상호작용
기타 업종에서 픽업을 켜면 해당 선택 옆에 오류를 표시하고 전체 등록 성공처럼 보이지 않는다. 카테고리·태그는 제공된 선택지에서 고른다.

#### 화면 상태와 문구
초기, catalog 로딩, 입력 오류, 사업자번호 중복, 픽업 자격 오류, 등록 중, 성공, 네트워크 오류. 성공: `매장이 등록되었습니다. 운영 정보를 설정해 주세요.`

#### 성공 후 이동
매장 관리 홈. 별도 승인 대기 화면으로 보내지 않는다.

#### 포함하지 않을 요소
사업자등록증·이미지, 국세청 확인 진행률, 플랫폼 승인·반려·보완, 운영자 ID 입력, 직원 초대.

### 4. 매장 관리 홈

#### 화면 목적
1차 MVP 관리 기능의 진입점이다. 고도화 통계 대시보드와 구분한다.

#### 반드시 포함할 요소
매장명·운영 상태, 기본정보·운영시간·예약시간·메뉴·수용량·재고·예약·픽업 바로가기, 설정 미완료 안내, 최근 저장 실패 재시도.

#### 화면 상태
매장 없음, 정상 운영, 임시 휴무, 폐점, 일부 설정 없음, 조회 오류.

#### 포함하지 않을 요소
1차 MVP에서 예약률·취소율·노쇼·웨이팅·매출 차트.

### 5. 매장 정보 조회·수정 화면

#### 화면 목적
등록된 매장의 공개 기본정보와 운영 모드를 확인하고 허용된 항목을 수정한다.

#### 반드시 포함할 요소
등록 정보 표시, 수정 가능한 이름·설명·지역·주소·카테고리·태그·운영 모드, 읽기 전용 또는 제한된 사업자번호·업종, 저장·취소·이탈 확인.

#### 화면 상태
조회 로딩, 수정 전·수정됨, 검증 오류, 픽업 자격 오류, 저장 중·완료·충돌.

#### 포함하지 않을 요소
이미지, 입점 재심사, 플랫폼 강제 상태 변경.

### 6. 운영시간 관리 화면

#### 화면 목적
요일별 복수 영업 구간과 브레이크타임의 전체 주간 설정을 편집한다.

#### 반드시 포함할 요소
월~일, 휴무 토글, 영업 시작·종료, 구간 추가·삭제, 브레이크타임, 요일 복사, 변경사항 요약, 전체 저장, 이탈 확인.

#### 화면 상태와 문구
설정 없음, 로딩, 편집, 구간 역전·중첩·브레이크 충돌, 저장 중·완료·충돌. `변경해도 기존 예약은 자동으로 이동하거나 취소되지 않습니다.`

### 7. 예약 접수 시간대 관리 화면

#### 화면 목적
영업시간 안에서 실제 예약을 받는 요일·시간 구간을 설정한다.

#### 반드시 포함할 요소
현재 영업시간 참조, 요일별 접수 구간, 추가·삭제·복사, 브레이크 충돌 표시, 전체 저장.

#### 포함하지 않을 요소
인원·팀 수 한도 입력. 이는 수용량 화면에서 관리한다.

### 8. 메뉴 목록·등록·수정 화면

#### 화면 목적
메뉴 기본정보와 대표 여부, 게시·노출·판매 축을 관리한다.

#### 반드시 포함할 요소
- 목록: 메뉴명, 가격, 대표, 버전, 노출, 판매, 홀드·픽업 허용, 수정
- 필터: 상태·대표 여부, 검색
- 폼: 이름, 설명, 원화 정수 가격, 대표 여부, 주 카테고리, 보조 0~5개, 로컬 태그, 홀드·픽업 허용
- 상태 축: 초안/예약 게시/게시/종료, 노출/숨김, 판매/일시중지
- 저장·취소·이탈 확인

#### 화면 상태
메뉴 없음, catalog 로딩, 검증 오류, 허용되지 않은 상태 전이, 저장 완료·충돌.

#### 포함하지 않을 요소
1차 MVP 이미지, 옵션, 알레르기, 원산지, 주류, 시간대별 수량 직접 입력.

### 9. 날짜별 예약 수용량 관리 화면

#### 화면 목적
날짜·시간 구간별 최대 인원·팀 수와 일행 조건을 설정한다.

#### 반드시 포함할 요소
날짜 선택, 시간 버킷 표, 최대 인원·팀, 최소·최대 일행, 영유아 허용, 현재 점유·남은 수용량, 전체 저장, 변경 영향 안내.

#### 화면 상태와 문구
설정 없음, 점유 있음, 유효성 오류, 현재 점유보다 작은 한도, 동시 변경 충돌. `기존 예약은 유지되며 신규 예약 가능 수량만 조정됩니다.`

### 10. 메뉴 수량·품절 관리 화면

#### 화면 목적
메뉴·날짜·제공 구간별 총 공급과 온라인·현장·공유 수량을 관리한다.

#### 반드시 포함할 요소
날짜·메뉴 필터, 버킷 목록, 총 공급, 온라인 홀드, 현장, 공유, 사용·잔여, 판매 가능/품절, 신규 버킷, 전체 배분 수정, 저장 확인.

#### 화면 상태와 문구
버킷 없음, 합계 불일치, 사용량 이하 축소, 품절, 다시 판매 가능 조건 미충족, 충돌. 일반 예약 메뉴 홀드와 픽업이 온라인 수량을 함께 사용할 수 있음을 안내한다.

#### 포함하지 않을 요소
POS·식재료 재고, 플랫폼 보정, 메뉴 기본정보 수정.

### 11. 예약 목록 화면

#### 화면 목적
현재 매장의 예약을 날짜와 상태별로 찾고 상세 처리로 진입한다.
#### 반드시 포함할 요소
날짜·상태 필터, 검색, 페이지 이동, 상태·예약번호·시간·인원·대표 메뉴 요약, 상세 이동, 빈 상태.

#### 상태
예약 완료·취소·방문 완료만 표시한다. 결제·체크인·노쇼 상태를 섞지 않는다.

#### 포함하지 않을 요소
다른 매장 예약, 웨이팅, 결제 상태, 목록에서 확인 없이 즉시 취소하는 액션.

### 12. 예약 상세·처리 화면

#### 화면 목적
예약 스냅샷을 확인하고 허용된 취소 또는 방문 완료 명령을 실행한다.
#### 반드시 포함할 요소
예약 스냅샷, 사용자 최소 연락정보, 인원 구성, 메뉴·수량, 취소 이력, `매장 사유 취소`, `방문 완료`, 확인 모달과 사유 입력.

#### 화면 상태와 문구
조회 중, 찾을 수 없음, 이미 취소·완료, 동시 상태 변경, 취소 완료, 방문 완료. 방문 완료는 수량 복구처럼 표현하지 않는다.

#### 포함하지 않을 요소
범용 상태 선택, 예약 수정, 환불, 체크인, 노쇼.

### 13. 픽업 목록·상세·처리 화면

#### 화면 목적
현재 매장의 픽업 예약을 조회하고 취소 또는 수령 완료한다.
#### 반드시 포함할 요소
날짜·상태 필터, 예약 완료·취소·수령 완료, 픽업 시각·메뉴·수량, 상세, 매장 사유 취소, 수령 완료, 확인 모달.

#### 화면 상태
픽업 비활성 매장에서는 내비게이션 자체를 숨긴다. 처리 충돌·취소 불가·완료 상태를 포함한다.

#### 포함하지 않을 요소
준비 완료, 배달, 결제·환불, 좌석 예약 수용량.

### 14. 대표자 내 정보 화면

#### 화면 목적
대표자 계정 정보를 확인하고 표시 이름을 수정한다.
#### 반드시 포함할 요소
읽기 전용 이메일·휴대전화·계정 상태, 표시 이름 편집, 저장·취소, 로그아웃.
#### 화면 상태
조회·편집·검증 오류·저장·충돌·세션 만료.
#### 포함하지 않을 요소
1차 MVP 비밀번호 찾기·변경, 직원, 탈퇴, 프로필 이미지.

---

## 2차 MVP 영향

자연어 검색, 개인화·품절 대체·주변 매장 추천, 카카오맵은 고객 탐색 기능이다. 식당 대표자용 별도 관리 화면을 임의로 추가하지 않는다. 향후 운영자용 계약이 정해지는 경우에만 독립 모듈로 추가한다.

## 고도화 화면

### 15. 오늘 운영 대시보드
#### 화면 목적
오늘의 예약·취소·노쇼·웨이팅 운영 상황을 요약한다.
#### 반드시 포함할 요소
오늘 예약 팀·인원, 예약률, 수용량 사용률, 취소·노쇼, 웨이팅 요약, 데이터 기준 시각.
#### 화면 상태
로딩, 데이터 없음, 집계 지연, 일부 카드 실패, 정상. 1차 관리 홈과 분리한다.

### 16. 웨이팅 사용 설정 화면
#### 화면 목적
매장의 웨이팅 접수 조건과 운영 여부를 설정한다.
#### 반드시 포함할 요소
사용 여부, 현장·원격 조건, 운영시간, 신규 접수 중지, 저장 확인, 기존 대기팀 영향.
#### 화면 상태
미사용, 사용 중, 접수 중지, 저장 중·완료·충돌.

### 17. 실시간 웨이팅 목록·상세 화면
#### 화면 목적
대기팀 순서와 상태를 실시간으로 보고 호출·입장 처리한다.
#### 반드시 포함할 요소
순번, 인원, 등록 시각, 예상 대기, 호출·재호출·입장 처리, 마지막 갱신.
#### 화면 상태
대기·호출·입장 완료·취소·미응답, 연결 끊김·재연결, 동시 처리 충돌.

### 18. 체크인·노쇼 관리 화면
#### 화면 목적
예약 고객의 도착 확인과 노쇼 후보·확정 절차를 관리한다.
#### 반드시 포함할 요소
예약별 체크인, QR·확인번호 결과, 노쇼 후보, 유예시간, 확정, 처리 이력.
#### 화면 상태
미체크인, 체크인 완료, 코드 오류, 노쇼 후보, 유예 중, 확정, 충돌.
#### 포함하지 않을 요소
단순 취소와 노쇼를 같은 액션으로 만들지 않는다.

### 19. 결제·환불 상태 화면
#### 화면 목적
예약별 예약금 결제와 환불 결과를 확인한다.
#### 반드시 포함할 요소
예약금, 결제·환불 상태, 처리 시각, 실패·확인 중, 복구 필요, 상세 이동.
#### 화면 상태
결제 전·성공·실패·확인 중, 환불 요청·완료·실패.
#### 포함하지 않을 요소
카드정보 원문, 근거 없는 수동 성공 처리.

### 20. 매장·메뉴 이미지 관리 화면
#### 화면 목적
공개할 매장·메뉴 이미지를 업로드하고 순서와 대표 이미지를 관리한다.
#### 반드시 포함할 요소
업로드, 미리보기, 대표 지정, 순서, 삭제 확인, 파일 조건.
#### 화면 상태
업로드 전·중·완료·실패, 처리 중, 잘못된 파일, 삭제 완료.
#### 포함하지 않을 요소
사업자등록증을 공개 이미지와 같은 저장·표시 흐름으로 처리하지 않는다.

### 21. 추천 메뉴 3~5개 관리 화면
#### 화면 목적
고객 화면 상단에 노출할 추천 메뉴 3~5개와 순서를 정한다.
#### 반드시 포함할 요소
현재 추천 목록, 메뉴 검색·추가·제거, 드래그 순서, 최소·최대 제한, 게시 상태 검증, 저장.
#### 화면 상태
선택 부족·초과, 게시 불가 메뉴, 저장 중·완료·충돌.
#### 포함하지 않을 요소
1차 MVP의 메뉴별 `대표 여부`와 같은 설정으로 합치지 않는다.

## 최종 산출물 요구

각 화면에 목적, 진입 조건, 데스크톱·모바일 레이아웃, 모든 입력·표시 필드, 주요 액션, 확인 모달, 기본·로딩·빈·오류·완료 상태, 이동 관계, 제외 요소를 제공한다. 1차 MVP 전용과 고도화 추가본을 별도 페이지 세트로 전달한다.
